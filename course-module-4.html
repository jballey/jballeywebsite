Images and Alt Text

Alt text is a short written stand-in for an image. Screen readers read it aloud, and it shows when the image fails to load.

Describe the Purpose

Ask what the image is doing in the lesson, then write that.

  • Keep it short, usually one sentence.
  • Leave out phrases such as image of or picture of. The screen reader already announces an image.
  • If the image contains text, include that text.

Decorative Images

Borders, dividers and background textures add nothing to the lesson. Give them empty alt text so screen readers skip them.

Charts and Diagrams

State the main point in the text beside the chart. The alt text can then be brief, such as: Bar chart of completion rates, described below.
